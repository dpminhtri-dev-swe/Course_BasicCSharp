## Ngày 1

### Điều mới học được
- Học các dang toán tử như + , - , * , / , %
- c++ vầ ++c đều thay đổi giá trị của c ban đầu
- c++ : dùng giá trị cũ trước rồi mới tăng
``` CSharp
int c =3 ;
d= 2 * 3++
```
=> lúc này d = 7 , c =4
```
- ++c :  tăng giá trị trước rồi dùng để tính toán
```CSharp
c=3 ;
d= 2* ++c
```
=> Llúc này d =8 , c =4

- Chỗi có thể rỗng nhưng ko được null, nếu muốn khai báo null thì : string? x = null , lúc này string mới nhận giá trị null
- int.Parse và Int32.Parse là như  nhau

- Với toán tử và &&  , thì 2 vế đúng => cả biểu thức đúng
